# RAG based PFD Q&A Application

## Tech Stack 
  - llama Index
  - Gemini API
  - Inngest
  - Qdrant Vector Database
  - FastAPI for Backend
  - Streamlit for Frontend

## Description 
RAG based Q&A application that uses Gemini API and RAG based system to retrieve relevant data from the uploaded PDFs for context to give relevant output.
